# Ekaterina Art Platform MVP

MVP сайта-платформы личного бренда Екатерины Преображенской — мастера авторского интерьерного декора ручной работы.

## Стек

- Next.js App Router
- TypeScript
- Tailwind CSS
- Моковые данные вместо базы
- Архитектура подготовлена к Supabase Auth, PostgreSQL и Storage

## Страницы

- `/` — главная страница бренда
- `/portfolio` — портфолио с категориями работ
- `/how-to-order` — этапы индивидуального заказа
- `/documents` — юридические документы и версии
- `/contacts` — контакты и форма обратной связи
- `/login` — экран входа, подготовленный под Supabase Auth
- `/account` — личный кабинет клиента, заявка, статусы, согласование ТЗ
- `/admin` — MVP админки мастера

## Дальнейшие интеграции

1. Supabase Auth для клиентов и администратора.
2. Supabase PostgreSQL для заказов, ТЗ, согласий и истории действий.
3. Supabase Storage для референсов, эскизов и фото готовых изделий.
4. Email-уведомления по событиям заказа.
5. Edge Function для фиксации IP-адреса и юридически значимых записей.
